# Règles de développement

Toujours :

Utiliser HTML5 sémantique.

Utiliser CSS Grid.

Utiliser Flexbox.

Utiliser les variables CSS.

Utiliser les commentaires.

Utiliser JavaScript ES6.

Utiliser des fonctions courtes.

Utiliser des noms explicites.

Conserver la même palette graphique.

Respecter le Responsive.

Ne jamais utiliser :

Bootstrap

Tailwind

React

Angular

Vue

jQuery

Ne jamais renommer :

Classes CSS

IDs

Fichiers

Structure HTML

Ne jamais réécrire un fichier complet si une modification ciblée suffit.

Toutes les modifications doivent être incrémentales.

Ajouter uniquement des commentaires :

// TODO PHP

// TODO SQL

// TODO API

Aucune donnée réelle.

Uniquement des données mockées.
