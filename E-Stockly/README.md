# E-Stockly

## Description

E-Stockly est une application web de gestion de stock destinée aux petites et moyennes entreprises.

L'objectif est de permettre aux administrateurs et aux gestionnaires de gérer efficacement :

- Les produits
- Les catégories
- Les fournisseurs
- Les clients
- Les entrées de stock
- Les sorties de stock
- Les ventes
- Les livraisons
- Les utilisateurs
- Les rapports
- Les statistiques

Le projet est développé progressivement.

Le Front-End est entièrement réalisé avant l'intégration du Back-End.
